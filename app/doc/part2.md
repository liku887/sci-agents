# 文献综述功能说明  
  
## 一、概述

文献综述助手包括**文献综述**。

## 二、功能模块说明

### 2.1 文献综述

**功能目标**  
基于用户提供的文献综述文本，进行系统性评价，并通过启发式、引导式对话帮助用户优化综述。

**使用步骤**
1. 登录系统后点击左侧导航栏的 **“文献综述”-“文献综述”** 按钮。
2. 上传你的文献综述后，开始对话（必须有文字输入）。
3. 智能体将会分析评价你的文献综述，数据来源包括**“文献精读”**中上传的文献(网页关闭重置)，并给出改进建议，例如：
![输入界面](/doc-images/2-1.png)
4. 可多次上传综述并参考，本流程结束。
