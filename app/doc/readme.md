## 功能模块

### 0. 新对话
- **新对话**：开启新的科研任务讨论。

### 1. 研究选题
- **文献检索**：快速查找相关文献资源。
- **文献精读**：提供文献摘要、核心观点提炼。
- **研究选题**：辅助确定研究方向与问题。

### 2. 文献综述
- **文献综述**：整理已有研究成果，形成综述报告。

### 3. 研究设计
- **假设生成与评估**：根据研究目标生成可行假设，并进行合理性评估。
- **引导研究设计**：提供实验、调查或建模方案设计指导。
- **方案验证与优化**：模拟或分析方案可行性，提供优化建议。

### 4. 学术写作
- **论文结构规划**：辅助搭建论文框架。
- **内容质量诊断**：检查逻辑、结构与内容完整性。
- **论文写作指导**：提供写作技巧与规范建议。
- **论文语句润色**：提升学术表达的清晰度和准确性。
- **图表数据整合支持**：支持图表绘制和数据整合。
- **参考文献格式化**：自动生成标准参考文献格式（如APA、MLA等）。

### 5. 数据分析
- **数据预处理**：清洗、转换和标准化数据。
- **分析方法选择**：推荐适合的数据分析方法。
- **具体分析**：执行统计分析、建模、可视化等操作。

### 6. 历史对话
- **历史对话**：支持查看、回顾和管理科研对话记录，便于连续研究。

---

## 使用方式

1. 输入论文类型、题目或研究方向（可选）。
2. 选择学科专业（可选）。
3. 点击 **开始对话**，根据科研流程模块逐步完成研究任务。
4. **科研智能体仅提供指导，不直接生成或代写论文内容。所有输出内容须由用户自行审核与采纳，以确保学术诚信。**
